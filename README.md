# Brilina AI Bot

My personal AI chat web app, powered by Groq, Google Gemini, and OpenRouter with automatic fallback.

Built with Next.js and Vercel AI SDK for smart, reliable responses.

## Features
- Multi-provider fallback (Groq first → Gemini → OpenRouter)
- Custom personality and knowledge
- Reusable API keys for other projects (e.g., trading bots)
